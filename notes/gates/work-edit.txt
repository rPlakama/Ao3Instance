== feature
GET /write/work/edit?work_id=   editor prefilled from AO3's own /works/<id>/edit
                                page (form#work-form values: title, rating,
                                warnings, fandom, categories, relationships,
                                characters, additional tags, language id,
                                summary, notes, end notes, collections, gifts);
                                rating/warning/category/language choices come
                                from the cached /works/new defaults.
POST /write/work/edit/preview   local validation (title 255, summary 1250,
                                notes/endnotes 5000, tag 150, <=75 tags,
                                title/rating/warning/fandom/language required) +
                                confirmation page, no network write
POST /write/work/edit           one PATCH /works/<id> with work[title|
                                rating_string|fandom_string|language_id|summary|
                                notes|endnotes|collection_names|recipients],
                                repeated work[archive_warning_strings][] and
                                work[category_strings][], optional relationship/
                                character/freeform strings. Chapter text is never
                                sent (edited from the chapter page).
Clearing: empty categories send the hidden empty work[category_strings][] value
AO3's own form emits, and relationship/character/freeform strings are always sent
(even empty), so clearing tags works.
Classification: 302 back to /works/<id> = updated (audit work-updated; the UI
only offers this on the account's own works, because AO3's ownership filter
also redirects non-authors to the work page); 200/422 #error = AO3 refusal shown
on the editor with fields preserved + audit failed; 429/login/auth/lost-cookie
typed; timeout = ambiguous, never retried. Governor edit_work = 10/h. If the
work was cached it is re-fetched once (best effort) and opened in the reader
with notice work_updated; an uncached work goes through /open/<id>.
