== feature
GET /my/works/<id>/chapters   AO3 chapter index via 30-min cached /works/<id>/navigate
                              (ol.chapter.index.group parser); chapters listed with
                              positions/dates, Edit links, Add Chapter; My Works rows
                              gained Chapters / Add Chapter.
GET /write/chapter/new        editor built from AO3's chapter form; next chapter number
GET /write/chapter/edit       editor prefilled from AO3's edit page (#chapter-form;
                              textarea values decoded from entities to raw author HTML)
POST /write/chapter/preview   local validation + confirmation, no network write
POST /write/chapter           one create (POST /works/<w>/chapters, post_without_preview_button
                              or save_button) or update (PUT /works/<w>/chapters/<c>,
                              update_button); fields chapter[title|position|wip_length|
                              summary|notes|endnotes|content]
Classification: 302 /works/<w>/chapters/<c> = saved (audit chapter-posted/chapter-updated,
new chapter id parsed; for updates the redirect must name the edited chapter — a 302 to the
work path is AO3's permission/not-found refusal, not a save); 302 .../<c>/preview = chapter
draft (audit chapter-draft); 200/422 #error = AO3 refusal shown on the editor with text
preserved + audit failed; 429 / login / auth / lost-cookie typed; timeout = ambiguous, never
retried. Governor chapter = 10/h.
After success the cached work is re-fetched once (best effort) so the reader shows it.

== contract details validated against the research pass
- chapter[wip_length] "?" (AO3's "total unknown" value) is accepted by local
  validation and preserved through the editor; the "of" field is a text input
  so the browser does not drop it.
- navigate display_title carries a "<position>. " prefix: the parser strips it
  before rendering the chapter list.
- editor textarea values are decoded author HTML (single escape on render), so
  submitting them back does not double-escape.
