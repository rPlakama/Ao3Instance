== feature
GET /works/new          composer built from AO3's own new-work form options
                        (ratings, warnings, categories, numeric language ids,
                        creator pseuds parsed in src/ao3/compose.rs; cached 10m)
POST /write/work/preview local validation + confirmation page; no network write
POST /write/work        one real POST /works on AO3; publish (post_button) or
                        save draft (save_button); intent/audit + governor
                        (post_work 3/hour); ACK: header "Post" link.

Classification: 302 /works/<id> = published (audit work-posted; app redirects to
/open/<id> and caches/opens the new work); 302 /works/<id>/preview = draft
(audit work-draft; AO3 deletes drafts ~29 days); 200 #error = failed with AO3's
own messages shown and the composed text preserved; 429 = rate limited;
network timeout = audit ambiguous, no retry, composer says "check AO3 first".

Local validation mirrors AO3 model limits (title 1-255, summary 1250, notes
5000, tag 150 chars, max 75 user-defined tags, content 10-510000, required
rating/warning/fandom/language/pseud). AO3 form contract verified against the
pinned clone (works_controller.rb#create 289-319, _standard_form, _work_form_tags,
_work_form_author byline, _posting_fieldset): singular
work[chapter_attributes][content], work[author_attributes][ids][], button names
post_button/save_button (values irrelevant), no POST /works/preview.
