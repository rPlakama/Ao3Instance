                        refusal shown on the drafts list + audit failed.

                        DELETE /works/:id; 302 /users/<login>/works[/drafts] =
                        deleted (audit work-deleted, local cached work removed,
                        user list cache invalidated).

greeting menu + dashboard Writing group (My Works, My Drafts, Post a new work
only when the write switch is on); actions hidden when writes are disabled.
