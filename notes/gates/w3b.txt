== design notes
- FTS5 table + INSERT/UPDATE/DELETE triggers: one writer (works), no app-side
  reindex step to forget; migration backfills pre-existing cache rows.
- Search input is quoted token-by-token with prefix matching, so user text is
  data, never FTS syntax.
